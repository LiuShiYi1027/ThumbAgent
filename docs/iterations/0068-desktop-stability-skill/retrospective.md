## 偏差与限制

- 技能文档里的循环上限仍是 600 秒 / 200 次；短时间盒靠任务 deadline。到点结束时，收尾日志和崩溃判定可能还没发生。确认文案按这个结果说明。
- `duration_seconds` 与 `max_actions` 只做提交声明，不改变循环天花板。
- 首次真机点击被 `INVALID_ARGUMENT` 拒绝：稳定性任务创建同样要求幂等键，桌面原先只在自然语言任务上附带。已补上并加回归单测。
- **时间盒与 deadline 不匹配是真机常态**：9-22 REST 提交与 9-23 桌面提交两次短时运行
  都以 `timed_out`（`TASK_DEADLINE_EXCEEDED`）收场——120 秒遍历 + 启动与收尾日志超过
  180 秒 deadline。采样数据保留、报告可用，但用户每次都会看到「已超时」，观感上像失败。
  需要单独迭代调整 deadline 计算或缩短收尾窗口。
- macOS 中文输入法会把 `keystroke` 的 `.` 变成 `'`（拼音分词符）：AX 驱动表单时包名
  必须用剪贴板粘贴输入。仅影响脚本化操作，不影响真实用户。
