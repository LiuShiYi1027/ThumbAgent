# ITER-0055 Desktop UI Visual Redesign

> 文档状态：Completed
> 迭代状态：Completed
> 更新日期：2026-08-20

## 产品结果

桌面工作台从「能用的朴素表单」升级为有完整视觉语言的现代桌面工具：清晰的品牌区、
有层次的卡片与排版、精致的徽章/按钮/表单、设备画面的手机框呈现。功能、交互流程、
组件 props 与 IPC 契约完全不变。

## 范围

- `apps/desktop/src/index.css` 全量重写：设计 tokens（色彩/阴影/圆角/间距/字级）、
  header、面板、徽章、按钮、表单、对话框、时间线、设备画面、设置页。
- 组件层仅在视觉必需时做最小 class/markup 调整（不改行为、不改数据流）。
- 迭代文档与门禁。

## 非目标

- 不新增/修改任何 Runtime 端点、Contract、IPC 命令或组件状态逻辑。
- 不做暗色模式切换（tokens 为未来暗色预留，但本迭代只交付一套主题）。
- 不重构组件结构、不引入 UI 框架或 CSS-in-JS 依赖。

## 设计方向

- 现代浅色主题：分层画布背景 +  elevated 卡片（柔和阴影、弱化边框）。
- 单一品牌色（靛蓝）+ 语义色板；徽章统一为圆点+文字的小药丸。
- 字体沿用系统栈，建立字级/字重/字距层级（微标签大写、加字距）。
- 圆角体系 8/10/14px；过渡动效 120–160ms；焦点环统一。
- 设备截图以深色手机框呈现，强化「真机同屏」的产品感。

## 依赖与风险

- 纯 CSS 重写风险是遗漏既有 class 导致局部无样式；缓解：重写前盘点全部 class
  （index.css 684 行、12 个组件），重写后用 screencapture 截图目检各视图。
- 兼容性：无 Contract/API 变化；不需要 ADR、不需要真机高风险 E2E
  （无设备能力变化），以截图目检 + 门禁作为验收证据。
