# ITER-0056 Desktop Mono Brand Theme

> 文档状态：Completed
> 迭代状态：Completed
> 更新日期：2026-08-20

## 产品结果

把设计方向稿 3c（Mono 编辑风）忠实落地为桌面工作台主题：奶油纸底、近黑粗边框、
硬偏移阴影、粗黑字重、黑白编辑气质，仅保留极少量红点缀。界面从「通用精致」升级为
有明确品牌性格的视觉系统。功能、交互与组件结构不变。

## 范围

- `apps/desktop/src/index.css` 重写：tokens（纸底/墨色/硬阴影/圆角）、header 与圆形
  logo 章、卡片、印章式徽章、黑底主按钮（按压位移交互）、表单、表格、时间线方形节点、
  对话框、手机框、滚动条。
- 语义色（ok/warn/error/busy）在 mono 语言下重绘为墨色描边印章，保持可区分。
- 迭代文档与截图目检。

## 非目标

- 不改组件 TSX 结构、不加新依赖、不动任何交互逻辑。
- 不做暗色版本；不追求与稿子逐像素一致（稿为 AI 生成参考，落地以 CSS 可实现性为准）。

## 设计决策

1. 以 `local/design-directions/direction-3c-mono.png` 为视觉基准（用户从 4 个候选中选定）。
2. 色板：纸底 `#faf6ef`、卡片 `#fffdf8`、墨色 `#1a1915`、唯一点缀红 `#e02d2d`
   （logo 章角点）；语义色保留绿/黄/红/紫但降饱和、统一墨色描边。
3. 硬阴影统一 `3px 3px 0` 墨色；按钮按压用 translate 位移模拟（不动画颜色以外的属性）。
4. 徽章做成「印章」：墨色 1.5px 描边 + 微旋转（仅标题行徽章，克制使用）。
5. 时间线节点由圆点改为方块，失败为红方块。
6. 字体沿用系统栈，标题 800 字重 + 负字距模拟 grotesque 感。
7. 无 Contract/API/交互变化；不需要 ADR 与真机 E2E，验收为截图目检 + 门禁。

## 风险

- 高对比黑白在小字号上易显脏：正文字号保持 13.5px、墨色用 `#1a1915` 而非纯黑。
- 硬阴影在密集列表中可能吵闹：表格行、时间线条目不使用硬阴影，仅卡片与按钮使用。
